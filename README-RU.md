# VyronGram Desktop

VyronGram — быстрый и функциональный десктопный клиент Telegram с расширенными возможностями кастомизации и приватности.

## Особенности
- **Ghost Mode (Режим невидимки):** Гибкая настройка скрытия статуса «в сети», набора текста, просмотра историй и прочтения сообщений.
- **История сообщений:** Локальное сохранение удаленных сообщений и истории изменений.
- **Продвинутая кастомизация:** Тонкая настройка интерфейса чатов, шрифтов, скруглений аватаров и контекстных меню.
- **Безопасность:** Прямое подключение к официальным серверам Telegram по протоколу MTProto.
