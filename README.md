# VyronGram Desktop

VyronGram is a high-performance desktop client based on the Telegram MTProto API, focused on customization and advanced productivity.

## Features
- **Ghost Mode:** Stay stealthy with granular control over read receipts, typing status, and stories.
- **Message History:** Local preservation of message edits and deleted messages.
- **Enhanced Customization:** Customizable themes, chat UI layouts, fonts, and avatars.
- **Security & Speed:** Direct connection to official Telegram servers via modern MTProto protocol.
